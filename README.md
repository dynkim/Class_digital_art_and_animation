# 3D 테크닉 I · 1주차 웹 슬라이드

승인된 수업 슬라이드 형식을 유지한 47장 브라우저 프레젠테이션입니다. 캔버스는 960 × 540, 글꼴은 Pretendard이며 각 텍스트와 미디어 프레임의 위치·크기·색상을 원본과 동일하게 저장합니다. 기존 `sources/` 자료는 변경하지 않습니다.

## 실행

이 폴더를 정적 웹 서버로 제공하면 됩니다. 별도 패키지 설치나 빌드 과정은 없습니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. JSON을 불러오기 때문에 `index.html`을 `file://`로 직접 여는 방식은 지원하지 않습니다. GitHub Pages를 사용할 때는 이 파일들이 있는 브랜치의 루트를 배포 폴더로 선택합니다.

## 조작

- 다음/이전: 화면 버튼, 방향키, Page Down/Page Up
- 첫 장/마지막 장: Home/End
- 전체 화면: 화면 버튼 또는 F
- 목차: 목차 버튼
- 특정 슬라이드: URL 끝에 `#slide-17`처럼 번호 지정
- 영상 컨트롤에 포커스가 있으면 키보드 조작은 영상에 전달됩니다.

## 파일

- `index.html`, `styles.css`, `app.js`: 브라우저 슬라이드 플레이어
- `slides/deck.json`: 47장 슬라이드의 텍스트, 좌표, 글자 크기, 색상
- `slides/media.json`: 미디어 슬롯 69개의 연결 정보
- `assets/fonts/`: Pretendard Regular/Bold와 SIL Open Font License
- `sources/`: 기존에 업로드한 수업 자료

`deck.json`의 `box`는 `[x, y, width, height]`이며 단위는 px입니다. `pt`는 원본 슬라이드의 포인트 크기입니다. 화면에 맞춰 캔버스 전체를 같은 비율로 확대·축소합니다. 이전에 글이 많던 원본 17·27번 슬라이드는 각각 두 장으로 나누었으며, `sourceSlide`가 원본 번호를 보존합니다.

## 이미지·영상 연결

현재 모든 `src`는 비어 있습니다. 기존 이미지를 다운로드하거나 읽어 연결하지 않았습니다. 이미지·영상 프레임은 강의 형식에 맞춰 그룹화되어 있으므로 원본 이미지 하나와 프레임 하나가 반드시 일치하지는 않습니다.

1. `slides/media.json`에서 해당 슬라이드의 슬롯을 찾습니다. `s17-m01`은 웹 슬라이드 17번의 첫 미디어 프레임입니다. `title`과 `sourceSlide`로 대상을 확인할 수 있습니다.
2. `type`을 `image` 또는 `video`로 지정합니다.
3. `src`에 실제 이미지/영상 파일 경로나 직접 접근 가능한 URL을 넣습니다.
4. 이미지 설명을 `alt`에 적습니다. 기본 `fit: "contain"`은 잘림 없이 전체를 표시합니다. 의도적인 크롭에만 `cover`를 사용합니다.
5. 커밋하고 배포된 페이지를 새로고침합니다.

`sources/`로 시작하는 경로는 이 저장소 `main` 브랜치의 raw GitHub 파일로 해석됩니다. 따라서 별도 웹 호스팅에서도 저장소의 미디어를 직접 사용할 수 있습니다. 다른 상대 경로는 웹 페이지 주소를 기준으로 해석되며, `https://`로 시작하는 직접 파일 URL도 사용할 수 있습니다. `repositoryBaseUrl`에서 저장소나 브랜치를 바꿀 수 있습니다.

영상은 브라우저에서 재생 가능한 MP4/WebM 파일을 사용합니다. GitHub의 파일 보기 페이지나 YouTube 페이지 URL 자체는 영상 파일이 아닙니다. 영상은 자동 재생하지 않고 사용자가 재생할 때 불러옵니다. 다른 슬라이드로 이동하면 재생 중인 영상은 일시 정지됩니다. 미디어는 해당 슬라이드에 진입할 때만 연결하고, 아직 연결하지 않은 프레임은 원본 플레이스홀더를 유지합니다.

## 배포

저장소 루트가 그대로 정적 웹 빌드입니다. GitHub Pages 또는 다른 정적 호스팅에서 `index.html`과 모든 동반 파일을 함께 제공하면 됩니다. 기존 Google Slides와 PPTX는 이 웹 빌드와 별개로 유지됩니다.
